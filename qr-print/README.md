# QR-листы для печати

На каждом листе только логотип MAGNIT, название MAGNIT и QR-код. Без адреса и подписей. Под кодом оставлено свободное поле, чтобы на телефоне его не закрывал нижний интерфейс.

- `magnit-qr.png` / `magnit-qr.jpg` - https://magnitdubai.ae/
- `magnit-qr-ru.png` / `magnit-qr-ru.jpg` - https://magnitdubai.ae/ru/
- `magnit-qr-ar.png` / `magnit-qr-ar.jpg` - https://magnitdubai.ae/ar/

Пересобрать: `python3 tools/build.py` и `python3 tools/make_qr_sheets.py`.
